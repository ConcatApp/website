Two ways in:

1. **[The download picker](/#download)** detects your operating system and processor and hands you
   the right build. Start there.
2. **[GitHub Releases](https://github.com/jub0t/Concat/releases)** has every build for every
   platform, with installers, packages and checksums, for when you want to pick.

Concat is in beta: it works, and it still has edges.
[Say so](https://github.com/jub0t/Concat/issues) when you find one.

## Windows

A setup program or an MSI package, for x64 (Intel and AMD) machines. Run it and follow the
prompts. There is no Windows on ARM build: it is paused since 0.2.7, whose ARM program crashed at
start ([#326](https://github.com/jub0t/Concat/issues/326)).

The builds are not code-signed, so SmartScreen may stop the first launch. Click **More info**,
then **Run anyway**. An MSI install updates itself from the next MSI; the setup program updates
from inside the app (see [Update Concat](/guides/update)).

If the window closes in its first seconds, the graphics driver is the usual cause. See
[report a problem](/guides/report-a-problem#the-window-closes-or-draws-garbage) for the
workaround; from 0.2.8 Concat falls back to drawing in software by itself after such a launch.

## macOS

A disk image for Apple Silicon and for Intel. Open it and drag Concat to Applications. Apple
Silicon Macs need macOS 12 or later.

The 0.2.7 Intel build closes at launch on macOS 12: it needs macOS 13.4. From 0.2.8 Intel Macs
open on macOS 12 again, and only the AI features that use ONNX Runtime (background removal, the
smart brush, Enhance and Chatterbox) need 13.4; on 12 they say so and the rest of the app works.

The builds are unsigned, so macOS may say the app is damaged or cannot be opened. Clear the
quarantine flag once, in Terminal:

```sh
xattr -dr com.apple.quarantine /Applications/Concat.app
```

## Linux

AppImage, `.deb`, `.rpm` and an Arch package, for x86_64 and ARM64.

- **AppImage**: mark it executable first, then run it. `chmod +x Concat-*.AppImage`
- **Debian and Ubuntu**: `sudo apt install ./Concat-*.deb`
- **Fedora and openSUSE**: `sudo dnf install ./Concat-*.rpm`
- **Arch**: `sudo pacman -U Concat-*.pkg.tar.zst`
- **Flatpak**: [Flatpark](https://flatpark.org/apps/app.concat.editor/) is a community remote that
  wraps the x86_64 `.deb` of each release and updates with it.

Dropped files, the frameless window's edge resize and the dock entry all work on native Wayland.

Two 0.2.7 problems fixed in 0.2.8: the AppImage can crash as its window opens under X11
([#379](https://github.com/jub0t/Concat/issues/379)); use the `.deb`, `.rpm` or Arch package
meanwhile. And on GNOME a folder dialog (Browse in New project, Export or Open) can hang on a
first run, because the default `Concat` folder on the Desktop does not exist yet; create
`~/Desktop/Concat` first.

## Android

An APK for 64-bit ARM phones and tablets, Android 8.0 or later. Android asks you to allow
installs from this source the first time. In 0.2.7 a device with no Vulkan driver closes the app
as it opens; 0.2.8 falls back to OpenGL ES. The phone layout is its own editor, not a shrunken desktop: see
[Concat on a phone](/guides/phone).

## iOS and iPadOS

An IPA for iPhone and iPad (iOS and iPadOS 15 or later), in beta. It is not on the App Store:
install it by sideloading with the tool you already use for that (AltStore, Sideloadly and the
like).

> [!WARNING]
> In 0.2.7, **Import media** on an iPhone or iPad does nothing, so the app cannot bring in a
> clip. 0.2.8 fixes it: Import asks Photos or Files.

## Checking a download

Every release ships a `SHA256SUMS` file next to the binaries, and the download picker prints the
checksum of the file it points to. Compare the two if you want to verify what you downloaded:

```sh
shasum -a 256 Concat-0.2.7-macos-arm64.dmg
```

## First launch

Concat opens on the start screen: **New project** on the left, your recent projects on the right.
Nothing to sign in to. The AI features (captions, voices, cutout) need a model each, which you
download from Settings the first time you use one; see [the AI models](/guides/offline-models).
