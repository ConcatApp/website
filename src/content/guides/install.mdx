Two ways in:

1. **[The download picker](/#download)** detects your operating system and processor and hands you
   the right build. Start there.
2. **[GitHub Releases](https://github.com/jub0t/Concat/releases)** has every build for every
   platform, with installers, packages and checksums, for when you want to pick.

Concat is in beta: it works, and it still has edges.
[Say so](https://github.com/jub0t/Concat/issues) when you find one.

## Windows

A setup program or an MSI package, for x64 (Intel and AMD) machines. Run it and follow the
prompts. There is no Windows on ARM build: it is paused since 0.2.7, whose ARM program crashed at
start ([#326](https://github.com/jub0t/Concat/issues/326)).

The builds are not code-signed yet, so SmartScreen stops the first launch. Click **More info**,
then **Run anyway**. Where Smart App Control is on, Windows refuses unsigned programs outright;
the [code signing policy](https://github.com/jub0t/Concat/blob/main/CODE_SIGNING.md) says why
the builds are unsigned and what Concat sends over the network. An MSI install updates itself
from the next MSI; the setup program updates from inside the app (see
[Update Concat](/guides/update)).

If the window closes in its first seconds, the graphics driver is the usual cause. Concat notices
such a launch and draws in software from the next start; see
[report a problem](/guides/report-a-problem#the-window-closes-or-draws-garbage).

## macOS

A disk image for Apple Silicon and for Intel. Open it and drag Concat to Applications. Both need
macOS 12 or later. On an Intel Mac, the AI features that use ONNX Runtime (background removal,
the smart brush, Enhance and Chatterbox) need macOS 13.4; on 12 they say so and the rest of the
app works.

The builds are unsigned, so macOS may say the app is damaged or cannot be opened. Clear the
quarantine flag once, in Terminal:

```sh
xattr -dr com.apple.quarantine /Applications/Concat.app
```

## Linux

AppImage, `.deb`, `.rpm` and an Arch package, for x86_64 and ARM64.

- **AppImage**: mark it executable first, then run it. `chmod +x Concat-*.AppImage`
- **Debian and Ubuntu**: `sudo apt install ./Concat-*.deb`
- **Fedora and openSUSE**: `sudo dnf install ./Concat-*.rpm`
- **Arch**: `sudo pacman -U Concat-*.pkg.tar.zst`
- **Flatpak**: [Flatpark](https://flatpark.org/apps/app.concat.editor/) is a community remote that
  wraps the x86_64 `.deb` of each release and updates with it.

Dropped files, the frameless window's edge resize and the dock entry all work on native Wayland.

## Android

An APK for 64-bit ARM phones and tablets, Android 8.0 or later. Android asks you to allow
installs from this source the first time. The phone layout is its own editor, not a shrunken
desktop: see [Concat on a phone](/guides/phone).

> [!WARNING]
> No automated check has started this APK: the release's emulators run x86_64 and the APK is
> built for arm64. A phone with no Vulkan driver opens the app on OpenGL ES, a path that has only
> run on an emulator so far. If it does not open on your phone,
> [say so](https://github.com/jub0t/Concat/issues).

## iOS and iPadOS

An IPA for iPhone and iPad (iOS and iPadOS 15 or later), in beta. It is not on the App Store:
install it by sideloading with the tool you already use for that (AltStore, Sideloadly and the
like). **Import media** asks **Photos** or **Files**; see [Concat on a phone](/guides/phone).

## Checking a download

Every release ships a `SHA256SUMS` file next to the binaries, and the download picker prints the
checksum of the file it points to; the SHA256SUMS link under the picker is that same release's.
Compare the two if you want to verify what you downloaded:

```sh
shasum -a 256 Concat-0.2.8-macos-arm64.dmg
```

## First launch

Concat opens on its home page: **New project** and **Open project** at the top, your recent
projects under them, and links to these guides, the shortcuts, GitHub and Discord. Nothing to sign
in to. The AI features (captions, voices, cutout) need a model each, which you download from
Settings the first time you use one; see [the AI models](/guides/offline-models).
