Concat is in beta: it works, and it still has edges. The best way to help is to use a build, find
where it breaks, and say so.

## What to attach

Every run writes a log. **Settings › About** has the button that opens it along with the one that
copies your system information. Attach both to an
[issue on GitHub](https://github.com/jub0t/Concat/issues) and the report arrives with everything
it needs.

The last ten runs are kept, so yesterday's log is still there. Nothing is ever sent anywhere on its
own.

If Concat will not open far enough to reach Settings, the logs are in a `logs` folder here:

| System  | Folder                                                              |
| ------- | ------------------------------------------------------------------- |
| Windows | `%LOCALAPPDATA%\app.concat.editor\logs`                             |
| macOS   | `~/Library/Application Support/app.concat.editor/logs`              |
| Linux   | `~/.local/share/app.concat.editor/logs` (or under `$XDG_DATA_HOME`) |

A portable build with a `portable` folder beside the program keeps them in that folder instead.
Set **Log level** in Settings › General (or `CONCAT_LOG` in the environment for one run) to
Debug when a report asks for more.

From 0.2.8 every log starts with the build's commit, the system and the processor with the
instruction sets it has, and a crash that is not a panic (a driver, a missing instruction) still
writes one line saying what it was and in which module.

## The window closes or draws garbage

A graphics driver is the usual cause of a window that closes in its first seconds, or draws as
coloured dots.

> [!NOTE]
> **New in 0.2.8 (coming in the next release).** On Windows and Linux, start Concat with
> `CONCAT_GPU=software` in the environment to draw the window on the software rasteriser (WARP
> on Windows, lavapipe on Linux). If that fixes it, the driver is the problem. Concat also does
> this by itself: a launch that closes while starting is followed by one that draws in software,
> with a note on the start screen, until you turn **Settings › General › Draw on the GPU** back
> on.

On Windows, open a Command Prompt, run `set CONCAT_GPU=software`, then start `Concat.exe` from
that same window by its full path. On Linux, `CONCAT_GPU=software ./Concat-*.AppImage`. Include
the log and your graphics card in the issue either way.

## Where to ask

- **[GitHub Issues](https://github.com/jub0t/Concat/issues)** for bugs and requests.
- **[Discord](https://discord.gg/DVuPfpXfqP)** for questions and for a quick word before filing.
  Contributors are free to claim a `@Contributor` role in the server, just ask for it.
