Concat serves a JSON-RPC API, so scripts and AI agents can cut video with it too. A build from
source adds gRPC and a command-line tool, `concat-cli`. The [developer docs](/docs) are the reference. This page is the short version for people
who have never opened them.

## Three ways in

| Transport              | How you reach it                                                                                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **JSON-RPC 2.0 lines** | In every release: the window's **Settings › Remote** page (**Automation** from 0.2.8) serves it over TCP while the editor is open. From source: `concat-cli api` and `concat-cli serve` |
| **gRPC** over HTTP/2   | Build from source only: `concat-cli serve --grpc`, with the `grpc` feature. No release ships it                                                                                         |
| **MCP**                | Not shipped. An MCP server is being built ([#337](https://github.com/jub0t/Concat/issues/337)); [MCP](/docs/transports/mcp) says how to bridge today                                    |

JSON-RPC and gRPC carry the same methods, payloads and errors.

## Five things to know

1. **Call `version` first.** Its `capabilities` list says what this build serves.
2. **Projects are folders.** Every method names a project by its folder path, and the folder must
   be open first.
3. **Edits are commands.** `edit.apply` carries the window's own edit vocabulary, unchanged.
4. **Exports are jobs.** `export.run` returns at once; progress comes as events; one export runs at
   a time.
5. **Errors have codes.** Branch on `code`; show `message` to a person.
