Shortcuts are shown in the menus and in every tray button's tooltip, with the right keys for the
platform you are on.

## Project and window

| Action                         | macOS                     | Windows and Linux                                                                                                    |
| ------------------------------ | ------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Open project                   | <kbd class="kbd">⌘O</kbd> | <kbd class="kbd">Ctrl+O</kbd>                                                                                        |
| Import media                   | <kbd class="kbd">⌘I</kbd> | <kbd class="kbd">Ctrl+I</kbd>                                                                                        |
| Save                           | <kbd class="kbd">⌘S</kbd> | <kbd class="kbd">Ctrl+S</kbd>                                                                                        |
| Export                         | <kbd class="kbd">⌘E</kbd> | <kbd class="kbd">Ctrl+E</kbd>                                                                                        |
| Settings                       | <kbd class="kbd">⌘,</kbd> | <kbd class="kbd">Ctrl+,</kbd>                                                                                        |
| Close project                  | File menu                 | <kbd class="kbd">Ctrl+W</kbd>                                                                                        |
| Close window, exit, quit       | <kbd class="kbd">⌘W</kbd> | <kbd class="kbd">Alt+F4</kbd> (Windows), <kbd class="kbd">Ctrl+Q</kbd> (Linux)                                       |
| Open the File, Edit, View menu |                           | <kbd class="kbd">F10</kbd>, <kbd class="kbd">Alt+F</kbd>, <kbd class="kbd">Alt+E</kbd>, <kbd class="kbd">Alt+V</kbd> |

## Editing

| Action                        | macOS                                                                           | Windows and Linux                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Undo                          | <kbd class="kbd">⌘Z</kbd>                                                       | <kbd class="kbd">Ctrl+Z</kbd>                                                               |
| Redo                          | <kbd class="kbd">⇧⌘Z</kbd>                                                      | <kbd class="kbd">Ctrl+Shift+Z</kbd> or <kbd class="kbd">Ctrl+Y</kbd>                        |
| Split at playhead             | <kbd class="kbd">⌘B</kbd>                                                       | <kbd class="kbd">Ctrl+B</kbd>                                                               |
| Split tool (razor) on and off | <kbd class="kbd">B</kbd>                                                        | <kbd class="kbd">B</kbd>                                                                    |
| Select all                    | <kbd class="kbd">⌘A</kbd>                                                       | <kbd class="kbd">Ctrl+A</kbd>                                                               |
| Copy, paste, duplicate        | <kbd class="kbd">⌘C</kbd>, <kbd class="kbd">⌘V</kbd>, <kbd class="kbd">⌘D</kbd> | <kbd class="kbd">Ctrl+C</kbd>, <kbd class="kbd">Ctrl+V</kbd>, <kbd class="kbd">Ctrl+D</kbd> |
| Delete selection              | <kbd class="kbd">⌫</kbd>                                                        | <kbd class="kbd">Del</kbd> or <kbd class="kbd">Backspace</kbd>                              |
| Ripple delete (close the gap) | <kbd class="kbd">⇧⌫</kbd>                                                       | <kbd class="kbd">Shift+Del</kbd>                                                            |
| Mute the selected clip        | <kbd class="kbd">M</kbd>                                                        | <kbd class="kbd">M</kbd>                                                                    |
| Add to the selection          | <kbd class="kbd">⇧</kbd> or <kbd class="kbd">⌘</kbd> click                      | <kbd class="kbd">Shift</kbd> or <kbd class="kbd">Ctrl</kbd> click                           |

## Playback and the lanes

| Action                   | Key                                                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Play, pause              | <kbd class="kbd">Space</kbd>                                                                                                          |
| One frame back, forward  | <kbd class="kbd">←</kbd>, <kbd class="kbd">→</kbd>; with <kbd class="kbd">Shift</kbd> ten frames                                      |
| Go to start, end         | <kbd class="kbd">Home</kbd>, <kbd class="kbd">End</kbd>                                                                               |
| Snap to edges on and off | <kbd class="kbd">N</kbd>                                                                                                              |
| Preview axis on and off  | <kbd class="kbd">S</kbd>                                                                                                              |
| Pan tool on and off      | <kbd class="kbd">H</kbd>                                                                                                              |
| Zoom the lanes           | <kbd class="kbd">⌘=</kbd> or <kbd class="kbd">⌘+</kbd>, <kbd class="kbd">⌘-</kbd>; <kbd class="kbd">⌘</kbd> + wheel about the pointer |
| Scroll time              | <kbd class="kbd">Shift</kbd> + wheel, or a horizontal wheel                                                                           |

## The monitor

| Action              | macOS                                         | Windows and Linux                               |
| ------------------- | --------------------------------------------- | ----------------------------------------------- |
| Snap while dragging | hold <kbd class="kbd">⇧</kbd>                 | hold <kbd class="kbd">Shift</kbd>               |
| Pan the view        | <kbd class="kbd">⌥</kbd> drag, or middle drag | <kbd class="kbd">Alt</kbd> drag, or middle drag |
| Zoom the view       | <kbd class="kbd">⌘</kbd> + wheel              | <kbd class="kbd">Ctrl</kbd> + wheel             |
| Fit                 | double-click the ground                       | double-click the ground                         |

Shortcuts keep working with Caps Lock on. There is no J, K, L shuttle and no I and O for in and
out points yet.
